# 制度・給付金データ 収集状況(2026-09-06 時点)

23区の子育て支援制度データ。gitにコミット済み(PR #1 でmainにマージ)。

制度に加えて、全国共通の**予防接種スケジュール**(`vaccine_schedule` テーブル / `data/vaccines.csv`、27件)も収集済み。厚労省の予防接種スケジュール(2026年4月版・5種混合導入後)と know-VPD をもとに、ロタ〜二種混合まで。区に依存しないマスタデータ。

**本番D1への反映方法**: GitHub の Actions タブ →「Seed master data to Production D1」→ Run workflow → 入力欄に `seed` と入力して実行。
生成スクリプトは決定的な id を振り `INSERT OR REPLACE` を出力するので、CSVを直して再実行すれば本番に上書き反映される。

**参照API**(`backend/src/index.ts`、認証必須):
- `GET /api/programs?ward=&category=&hasDeadline=0|1&ageMonths=&q=` — 制度一覧(`{ total, items }`)
- `GET /api/programs/categories?ward=` — カテゴリ別件数
- `GET /api/programs/:id` — 単体
- `GET /api/vaccines?category=定期|任意` — 予防接種スケジュール(`{ total, items }`)
- `POST /api/tasks/generate {ward?, dryRun?}` — 世帯の区の「締切あり制度」から procedure_tasks を一括生成(既存はスキップ)
- `POST /api/tasks/from-program {programId, dueDate?}` — 制度1件を「やること」に追加
- `POST /api/tasks/from-vaccine {vaccineId}` — 予防接種1件を「やること」に追加(期限 = 誕生日 + 推奨月齢)

## ファイル構成

```
data/
  programs.csv              ← 統合済みの最終データ(このファイルがD1に入る実体)
  programs.generated.sql    ← programs.csv から自動生成されたINSERT文(git管理外でよい生成物)
  research/                 ← カテゴリごとの調査生データ(programs.csvにマージ済みだが記録として保持)
    shussan.csv       出産祝い金・出産費用助成
    sango-care.csv    産後ケア事業
    iryohi.csv        子ども医療費助成
    omutsu.csv        紙おむつ・育児用品支給
    vaccine.csv       任意予防接種費用助成
    helper.csv        産前産後家事育児支援ヘルパー
    hitorioya.csv     ひとり親家庭向け支援
    tateiji.csv       多胎児家庭向け支援
    hoikatsu.csv      保育園入園(保活)関連情報
scripts/
  csv-to-sql.js        CSV → D1用INSERT文への変換スクリプト
```

## 使い方(再投入する場合)

```bash
cd backend
node scripts/csv-to-sql.js data/programs.csv > data/programs.generated.sql
npx wrangler d1 execute xincere-db --local --file=schema.sql
npx wrangler d1 execute xincere-db --local --file=data/programs.generated.sql
```

## まだ集めていないデータ(候補)

要件定義書(README.md F-5)や既存アプリとの差別化検討の中で名前は挙がったが、未着手のもの:

- **子ども家庭支援センター等の相談窓口一覧**(住所・電話・LINE相談の有無) — 給付金ではないが実用性が高い。調査コストは低め

- **保育園入園(保活)の8区分の締切詳細** — 上記の通り概要のみ。深掘りする場合は追加調査が必要
- 学童保育(放課後児童クラブ)の入所基準 — ペルソナ(第一子・生後18ヶ月まで)からは時期的に外れるため優先度低
- 予防接種の**全国共通の定期接種スケジュールマスタ**(BCG・5種混合等) — 23区調査は不要、別途1回作れば済むマスタデータ。未着手

## データ品質についての注意

- 各行の `notes` 列に「要確認」「まとめサイト情報」「推定」等のフラグが入っている行は、公式ページで裏取りしきれなかったもの。**本番反映前・金額を含む行は特に人手レビュー推奨**(要件定義書 §7.2の方針通り)
- 出典が区公式(`*.lg.jp` / `*.tokyo.jp`)かどうかは `source_url` を見れば判断できる
- 「該当制度なし」の行は省略ではなく、調査した上で確認できなかったことを明示的に記録したもの
